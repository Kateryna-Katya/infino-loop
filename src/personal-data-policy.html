Политика обработки персональных данных

1. Общие положения

Настоящая политика определяет порядок обработки данных, предпринимаемые Infino Loop (далее — Оператор), для обеспечения безопасности информации наших пользователей.

2. Данные, которые мы обрабатываем

  • Имя и Email (при заполнении контактной формы).
  • Номер телефона (для обратной связи).
  • Обезличенные данные через файлы cookie и сервисы аналитики.

3. Цели обработки

Мы используем ваши данные исключительно для установления обратной связи, ответа на ваши запросы по разработке ботов и улучшения качества контента нашего блога.

4. Безопасность

Данные Пользователя никогда не будут переданы третьим лицам, за исключением случаев, предусмотренных законодательством ЕС. Вы можете отозвать согласие, написав на hello@infino-loop.org.

Этот сайт использует cookies для улучшения работы. Подробнее — в нашей Cookie политике.
